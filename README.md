# Regulatory change log

Live tracker of CFPB, FCC and FHFA rules and notices touching mortgage servicing, lending and automated calling, pulled from the Federal Register API, with change-management records (what changed, why, owner, approval, rollout plan, evidence) that export to Markdown or CSV.

Live: https://jakem-r.github.io/kastle-reg-tracker/

`data.json` is a daily snapshot written by the GitHub Action in `.github/workflows/refresh.yml`, used only if the live API call fails.

A tracker, not legal advice. Concept by Jake Makking-Robinson. Not affiliated with Kastle.
